ℹ️ ការណែនាំប្រើប្រាស់ (Guide)

១. របាយការណ៍ (Report Sheet)

  • ថ្ងៃទី / ខែ / ឆ្នាំ — កែកាលបរិច្ឆេទរបាយការណ៍
  • ក្រុមហ៊ុន — ប្តូរឈ្មោះ (លំនាំដើម AMFC)
  • ព័ត៌មានលម្អិតចំណាយ — សរសេរមុខចំណាយ + ចំនួនទឹកប្រាក់ (៛)
  • + បន្ថែមថ្មី — បន្ថែមជួរថ្មី
  • លុយធនាគារ ABA (Bank Money) — បញ្ចូលលុយក្នុងធនាគារ
  • ចំណាយសរុប (Total Expense) — គណនាស្វ័យប្រវត្តិ
  • នៅសល់ (Remind Balance) = Total − Bank Money
  • ហត្ថលេខា — Choose File ដាក់រូបហត្ថលេខា (អ្នកធ្វើបញ្ជី / អ្នកត្រួតពិនិត្យ)

២. បញ្ចូលចំនួន (Amount)

  • PC / Keyboard — វាយលេខដោយផ្ទាល់
  • Mobile / Touch — ចុចលើប្រអប់ → បើក Number Pad
  • Double-click បើក Number Pad ជានិច្ច

៣. Theme · Display · Plot Style

  • Theme: Monochrome · AMFC Blue · Midnight · Brand Accent
  • Display: Mobile View / Document View (A4)
  • Plot Style: Monochrome (ខ្មៅស) ឬ By Theme — សម្រាប់ Print/PDF

៤. ម៉ឺនុយ (☰ AMFC Menu)

  • Item List — ទៅកាន់តារាងចំណាយ
  • Search — ផ្តោតលើប្រអប់ស្វែងរកមុខចំណាយ
  • New Doc — បង្កើតរបាយការណ៍ថ្មី
  • Input — Paste / Import ទិន្នន័យ (csv, txt, Excel…)
  • Output Result — Preview · History · Result Section
  • History — Load · Delete · Filter by date · Import/Export
  • Save — រក្សាទុករបាយការណ៍
  • Feedback — ផ្ញើមតិ

៥. ប៊ូតុងខាងក្រោម

  • Preview — មើលរូបរាងមុនព្រីន

  • Print — ព្រីនទំព័រតែមួយ
